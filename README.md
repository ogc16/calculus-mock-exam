# Calculus II – Mock Exam

A mock examination website for **Calculus II**, containing **50 questions** with full worked solutions covering integration techniques and their applications.

## Features

- **50 exam questions** across a range of calculus topics
- **Show / Hide** individual solutions with a single click
- **Show All / Hide All** to toggle every solution at once
- **Print-friendly** layout — solutions are included when printing
- **MathJax** rendering for clean, professional mathematics
- **No build step** — open `index.html` directly in any browser

## Topics Covered

| Topic | Examples |
|-------|----------|
| Integration by Parts | `∫ x eˣ dx`, `∫ x² sin x dx`, `∫ e²ˣ cos x dx` |
| u-Substitution | `∫ sin³x cos x dx`, `∫ x/√(1−x²) dx` |
| Partial Fractions | `∫ 1/((x−3)(x−5)) dx`, `∫ (6x²−7x+6)/(x²(x−2)) dx` |
| Trig Substitution | `∫ √(4−x²) dx`, `∫ x³/√(x²+4) dx` |
| Completing the Square | `∫ 1/(x²+4x+13) dx` |
| Trig Identities | `∫ cos²x dx`, `∫ sin 3x cos 2x dx` |
| Implicit Differentiation | Tangent & normal lines, `dy/dx`, `d²y/dx²` |
| Equations | Trigonometric equations, log equations |

## Usage

1. Download or clone the repository
2. Open `index.html` in your browser
3. Click **Show Solution** to reveal worked answers

No internet connection required beyond the CDN-hosted MathJax and Tailwind CSS.

## Skills Tested

- Integration techniques: parts, substitution, partial fractions, trig substitution
- Solving trigonometric and logarithmic equations
- Implicit and parametric differentiation
